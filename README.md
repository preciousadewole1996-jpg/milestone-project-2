# Favorite Catering Services

A responsive front-end website for a Peterborough-based catering business. It helps customers see the services offered, get a quick price estimate and send an enquiry.

**Live site:** _add your GitHub Pages link_  |  **Repository:** _add your GitHub link_

## Purpose and target audience
- Couples and families planning weddings and parties
- Companies needing office or event catering

### User stories
1. As a customer, I want to see the services offered so I can decide if they suit my event.
2. As a customer, I want an instant estimate so I can plan my budget.
3. As a customer, I want to send an enquiry and get clear feedback that it worked.

## Features
- Responsive layout and mobile menu
- Service tags that show details on click
- Estimate calculator with input validation
- Contact form with validation and feedback
- `404.html` redirects visitors to the home page

## Technologies
HTML5, CSS3, JavaScript. No external libraries.
